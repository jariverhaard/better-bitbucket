# Better Bitbucket

A calmer dashboard for [stash.maxserv.com](https://stash.maxserv.com/dashboard): views for what needs your attention, filters per project, person, Jira status and review app, muting, a whitelist and blacklist for people, build status at a glance and eleven styles.

Better Bitbucket used to be called Stash Glass. If you installed Stash Glass, you already have it: it updates itself under the new name and keeps your settings.

## Install in Zen or Firefox

1. Download the `.xpi` file from [the latest release](https://github.com/jariverhaard/better-bitbucket/releases/latest).
2. Open `about:addons`, click the gear icon and choose **Install Add-on From File**.
3. Open <https://stash.maxserv.com/dashboard>.

The add-on is signed by Mozilla, so the signature check in Zen can stay on.

## Install in Chrome, Edge, Arc or Brave

1. Download `better-bitbucket-chrome-<version>.zip` from [the latest release](https://github.com/jariverhaard/better-bitbucket/releases/latest) and unzip it. You get a folder called `better-bitbucket`. Move it to a place where it can stay, for example your home folder.
2. Open `chrome://extensions` and turn on **Developer mode** in the top right.
3. Click **Load unpacked** and pick the `better-bitbucket` folder.
4. Open <https://stash.maxserv.com/dashboard>.

## Updates

In Zen and Firefox new versions install themselves. Zen checks about once a day, or right away through **Check for Updates** in `about:addons`.

Chrome only updates extensions from its own store by itself. To update there, download the zip of the newest release, replace the contents of your `better-bitbucket` folder with the new one and click the reload icon of Better Bitbucket in `chrome://extensions`. Your settings stay.

After an update the dashboard shows what is new, and the gift icon in the top bar lists every change.
